Concepts

  • A profile is one encrypted file on your computer. It holds everything below.
  • A vault groups items, like a folder (e.g. "Work", "Banking"). It can have its own icon and color.
  • An item is one account: its logins, passwords, websites, emails, phone numbers, TOTP codes and custom fields. Each field can hold several values.

A profile is protected by two passwords:

  • the primary password unlocks the profile: vault and item names, logins, websites, emails, phone numbers and clear custom fields become readable;
  • the secondary password decrypts the secrets (passwords, TOTP secrets, encrypted custom fields). It is only asked the first time a secret is needed.

Each profile also has a label: the only text readable without any password, shown in the list of profiles. It can be left empty to keep the profile anonymous; the username itself is encrypted.

There is no password recovery: if you lose one of them, the profile cannot be opened anymore.

Start screen

The start screen is shown inside the main window when bippass starts, and again whenever the profile is locked: this is also where you switch to another profile or create a new one. Until a profile is open, the toolbar only shows the theme button, the language selector and ⚙ Settings, reduced to Updates and Help.

Opening a profile

  1. Choose Open an existing profile.
  2. Click your profile under Existing profiles (shown by its label and the date of its last save), or use Browse… under Or choose a profile file for a file stored elsewhere. The last file opened is pre-selected. A file made by a newer version of bippass is greyed out.
  3. Type the primary password and press Enter or click Unlock. The secondary password will be asked later, only when needed.

Renaming or deleting a profile

Right-click a profile under Existing profiles: Rename the profile changes its name (its primary password is asked, the profile isn't opened); Delete the profile moves its file to the trash, after confirmation.

Creating a profile

  1. Choose Create a new profile, then type a Username and a Label. The label copies the username until you edit it; clear it to keep the profile anonymous. Several profiles may share a name.
  2. Choose the primary password (it opens the profile), typed twice to confirm it, then click Next.
  3. Choose the secondary password (it protects the secrets), typed twice too, then click Create the profile; Back returns to the first step, keeping what you typed. The profile is created, saved and opened right away.

The Show / Hide button next to each password field reveals what you typed.

Unlocking takes a few seconds on purpose: it makes guessing a password much slower for an attacker. Meanwhile, the window is darkened with a "please wait" message.

Main window

The window has a toolbar at the top and three columns:

  • left: the vaults of the profile;
  • middle: the items of the selected vault;
  • right: the open item, shown only once an item is opened.

Until a profile is open, and while it is locked, the three columns are replaced by the start screen.

Vaults (left column)

  • Click a vault to show its items. Vaults are always listed in alphabetical order.
  • + New vault creates an empty vault. Several vaults may share a name.
  • Right-click a vault for:
    • Rename;
    • Change icon: pick an icon in the grid (or None), then its color with Choose color. The grid always shows the shapes in black or white (as the theme); the Preview shows the chosen shape in the chosen color;
    • Delete: deletes the vault and all its items, after a confirmation telling how many items it holds.
  • Drop items onto a vault to move them there (see Items).

Items (middle column)

  • The top line shows the vault's name and how many items are shown out of the total.
  • Search an item… filters the items by name (letter case and accents are ignored).
  • The sort box orders the list by Name ("item2" before "item10"), Creation date or Last modified; the arrow button next to it reverses the order. Sorting only changes the display.
  • Double-click an item, or select it and press Enter, to open it on the right.
  • + New item creates an empty item and opens it directly in edit mode.
  • Right-click an item for Open, Rename, Change icon, Duplicate (a copy in the same vault) or Delete (after confirmation, cannot be undone). While the item is being edited on the right, Rename, Change icon and Duplicate are greyed out: save or cancel the edit first.
  • To move items to another vault, select them (Ctrl+click, Shift+click, or Ctrl+A for all), then drag them onto the target vault and confirm.

Item viewer (right column)

The header shows the item's name, its creation date, the date of its last change and its icon. Close hides the viewer.

Read mode

  • Only the fields that have a value are shown.
  • Click a value to copy it to the clipboard; it briefly turns green.
  • Secrets (passwords, encrypted custom fields) are masked and stay encrypted until you ask for them: Show / Hide reveals them, and clicking one copies it. The secondary password is asked the first time.
  • A copied secret is erased from the clipboard after 30 seconds, when the profile is locked and when the window closes, unless you copied something else meanwhile.
  • TOTP codes shows the current 6-digit code and the seconds left before it changes, while the profile is decrypted (🔒 otherwise: click to enter the secondary password). Clicking copies the code, never the secret.
  • Double-click a website, an email address or a phone number to open it in your browser, mail application or phone application, after confirmation.
  • A ⚠ marks a website, email or phone number that doesn't look valid (hover it for details).

Edit mode

Click Edit to switch to edit mode (the secondary password is asked if needed). Every field is then shown, in clear, and can be changed:

  • Type the item's name directly in the title.
  • + Add value adds a value to a field; ✕ next to a value removes it.
  • Generate, under Passwords, opens the password generator; the password it produces is added as a new value.
  • TOTP codes are edited as their Base32 secret (the key given by the website when you enable two-factor authentication).
  • + Custom field adds a field with a name of your choice, Clear (like a login) or Encrypted (like a password). A custom field can hold several values, each on several lines. In its header: its name (edit it to rename the field), ▲ / ▼ to move it, ✕ to remove it. Several custom fields may share a name.
  • Double-click the icon to change it: type in the search bar to filter the bundled logos (the first match is selected, Enter validates), pick one in the list, use Browse… to choose any image from your computer, or Remove for the default icon. Background color fills the transparent parts of the icon, to make a logo stand out on your theme; None keeps them transparent. The Preview next to it shows the final icon, logo and background, as the lists show it. The image itself is stored in the profile, so moving the profile to another computer keeps its icons.

Save applies every change to the item and returns to read mode: name, values, icon, and the custom fields added, renamed, moved or removed. Cancel discards them all.

If you switch to another item or vault, or close the viewer, with unsaved changes, bippass asks whether to Save, Discard or Cancel.

Changes applied to an item are kept in memory: they reach the disk when the profile is saved (see Saving).

Password generator

Choose the type of password, set its options, then click Generate (as many times as you like).

Random

  • Length: from 1 to 256 characters.
  • Lowercase (a-z), Uppercase (A-Z), Digits (0-9): the character classes to use.
  • Special characters: tick it to add special characters; the list can be edited, and ↺ restores the default one.

Easy to remember

  • Word language: English, French or Spanish words.
  • Number of words, Digits per word and Separator between words.
  • Capitalize each word.

Copy copies the result (erased from the clipboard after 30 seconds); Use this password adds it to the item; Cancel closes without using it.

Saving and locking

  • Changes are kept in memory until the profile is saved: with Save in the toolbar, Ctrl+S, or Ctrl+K (save and exit).
  • Encrypt forgets the secondary password: secrets are hidden again, until you enter it again.
  • Lock (or Ctrl+L) asks what to do with the edits of the open item, saves the profile, closes it (both passwords are cleared from memory) and goes back to the start screen: open it again with its primary password, open another profile or create one. If the save fails, the profile stays open.
  • After a period of inactivity (set in Preferences), bippass locks the profile the same way, applying the edits of the open item without asking. A dialog left open is closed first.
  • When you close the window, bippass asks what to do with the edits of the open item, then whether to save the unsaved changes.
  • Once the window is closed, the passwords are cleared from memory.

Your files

LocationContent
~/.bippass/profiles/<uuid>.bippassYour profiles, one file each, named after the profile's UUID (shown in Metadata). Back up this folder regularly.
~/.bippass/settings.jsonThe settings of this computer: the theme of the start screen and the last profile opened.
~/.bippass/logs/bippass.logUnexpected errors (the technical details, never a password)
