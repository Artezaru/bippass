Concepts

  • A profile is one encrypted file on your computer. It holds everything below.
  • A vault groups items, like a folder (e.g. "Work", "Banking"). It can have its own icon and color.
  • An item is one account: its logins, passwords, websites, emails, phone numbers, TOTP codes and custom fields. Each field can hold several values.

A profile is protected by two passwords:

  • the primary password decrypts the profile file;
  • the secondary password decrypts the secrets inside it (passwords, TOTP secrets, secret custom fields).

There is no password recovery: if you lose one of them, the profile cannot be opened anymore.

Launch screen

The language selector at the top right changes the language of the whole application.

Opening a profile

  1. Choose Open an existing vault.
  2. Click your profile under Existing profiles, or use Browse… under Or choose a vault file for a file stored elsewhere. The last file opened is pre-filled.
  3. Enter the primary password (Primary credentials), then the secondary password (Secondary credentials).

Creating a profile

  1. Choose Create a new profile and type a username. The screen shows where the profile will be saved (~/bippass/<username>.encrypted). A username already in use is refused.
  2. Choose the primary password and type it again to confirm, then do the same for the secondary password.

The Show / Hide button next to each password field reveals what you typed.

Main window

The window has a toolbar at the top and three columns:

  • left: the vaults of the profile;
  • middle: the items of the selected vault;
  • right: the open item, shown only once an item is opened.

Vaults (left column)

  • Click a vault to show its items. Vaults are sorted alphabetically.
  • + New vault creates an empty vault.
  • Right-click a vault for:
    • Rename;
    • Icon…: pick an icon in the grid (or None), then its color with Choose color…;
    • Delete: deletes the vault and all its items, after a confirmation telling how many items it holds.
  • Drop items onto a vault to move them there (see Items).

Items (middle column)

  • The top line shows the vault's name and how many items are shown out of the total.
  • Search an item… filters the items by name.
  • The sort selector orders them Alphabetic, Alphanumeric ("item2" before "item10") or by Date of last change; the arrow button next to it reverses the order.
  • Double-click an item, or select it and press Enter, to open it on the right.
  • + New item creates an empty item and opens it directly in edit mode.
  • Right-click an item for Open, Rename, Icon…, Duplicate (a copy in the same vault) or Delete (after confirmation, cannot be undone).
  • To move items to another vault, select them (Ctrl+click, Shift+click, or Ctrl+A for all), then drag them onto the target vault and confirm.

Item viewer (right column)

The header shows the item's name, the date of its last change and its icon. Close hides the viewer.

Read mode

  • Only the fields that have a value are shown.
  • Click a value to copy it to the clipboard; it briefly turns green.
  • Passwords are masked: Show / Hide reveals them. Copying always copies the real value.
  • TOTP codes shows the current 6-digit code and the seconds left before it changes. Clicking copies the code, never the secret.
  • Double-click a website, an email address or a phone number to open it in your browser, mail application or phone application, after confirmation.
  • A ⚠ marks a website, email or phone number that doesn't look valid (hover it for details).

Edit mode

Click Edit to switch to edit mode. Every field is then shown, in clear, and can be changed:

  • Type the item's name directly in the title.
  • + Add value adds a value to a field; ✕ next to a value removes it.
  • Generate, under Passwords, opens the password generator; the password it produces is added as a new value.
  • TOTP codes are edited as their Base32 secret (the key given by the website when you enable two-factor authentication).
  • + Custom field adds a field with a name of your choice: SCALAR for plain text, ENCRYPTED for a secret. ✕ in a custom field's header removes it.
  • Double-click the icon to change it: type in the search bar to filter the bundled logos (the first match is selected, Enter validates), pick one in the list, or use Browse… to choose any image from your computer.

Save applies the changes to the item and returns to read mode; Cancel discards them. The icon and the custom fields added or removed are applied right away, Cancel doesn't undo them.

If you switch to another item or vault, or close the viewer, with unsaved changes, bippass asks whether to Save, Discard or Cancel.

Changes applied to an item are kept in memory: they reach the disk when the profile is saved (see Saving).

Password generator

Choose the type of password, set its options, then click Generate (as many times as you like).

Random

  • Length: from 1 to 256 characters.
  • Lowercase (a-z), Uppercase (A-Z), Digits (0-9): the character classes to use.
  • Special characters: tick it to add special characters; the list can be edited, and ↺ restores the default one.

Easy to remember

  • Word language: English, French or Spanish words.
  • Number of words, Digits per word and Separator between words.
  • Capitalize each word.

Copy copies the result; Use this password adds it to the item; Cancel closes without using it.

Saving and auto-lock

  • Changes are kept in memory until the profile is saved: with Save in the toolbar, Ctrl+S, or Ctrl+K (save and exit).
  • When you close the window, bippass asks what to do with the edits of the open item, then whether to save the unsaved changes.
  • After a period of inactivity (set in Preferences), bippass applies the edits of the open item, saves the profile and closes. If the save fails, the window stays open.
  • Once the window is closed, the passwords are cleared from memory.
