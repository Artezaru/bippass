Principes

  • Un profil est un fichier chiffré sur votre ordinateur. Il contient tout le reste.
  • Un coffre regroupe des éléments, comme un dossier (par ex. « Travail », « Banque »). Il peut avoir sa propre icône et sa couleur.
  • Un élément correspond à un compte : ses identifiants, mots de passe, sites web, emails, numéros de téléphone, codes TOTP et champs personnalisés. Chaque champ peut contenir plusieurs valeurs.

Un profil est protégé par deux mots de passe :

  • le mot de passe primaire déverrouille le profil : les noms des coffres et des éléments, les identifiants, sites web, emails, numéros et champs personnalisés en clair deviennent lisibles ;
  • le mot de passe secondaire déchiffre les secrets (mots de passe, secrets TOTP, champs personnalisés chiffrés). Il n'est demandé que la première fois qu'un secret est nécessaire.

Chaque profil a aussi un libellé : le seul texte lisible sans mot de passe, affiché dans la liste des profils. Il peut rester vide pour garder le profil anonyme ; le nom d'utilisateur, lui, est chiffré.

Aucune récupération n'est possible : si vous perdez l'un des deux, le profil ne peut plus être ouvert.

Écran d'accueil

L'écran d'accueil s'affiche dans la fenêtre principale au démarrage de bippass, puis à chaque verrouillage du profil : c'est aussi là que vous changez de profil ou en créez un nouveau. Tant qu'aucun profil n'est ouvert, la barre d'outils n'affiche que le bouton de thème, le choix de la langue et ⚙ Paramètres, réduit à Mises à jour et Aide.

Ouvrir un profil

  1. Choisissez Ouvrir un profil existant.
  2. Cliquez sur votre profil sous Profils existants (affiché avec son libellé et la date de son dernier enregistrement), ou utilisez Parcourir… sous Ou choisissez un fichier de profil pour un fichier rangé ailleurs. Le dernier fichier ouvert est présélectionné. Un fichier créé par une version plus récente de bippass est grisé.
  3. Tapez le mot de passe primaire, puis appuyez sur Entrée ou cliquez sur Déverrouiller. Le mot de passe secondaire sera demandé plus tard, seulement si besoin.

Renommer ou supprimer un profil

Clic droit sur un profil sous Profils existants : Renommer le profil change son nom (son mot de passe primaire est demandé, le profil n'est pas ouvert) ; Supprimer le profil déplace son fichier dans la corbeille, après confirmation.

Créer un profil

  1. Choisissez Créer un nouveau profil, puis saisissez un Nom d'utilisateur et un Libellé. Le libellé recopie le nom d'utilisateur tant que vous ne le modifiez pas ; videz-le pour garder le profil anonyme. Plusieurs profils peuvent porter le même nom.
  2. Choisissez le mot de passe primaire (il ouvre le profil), saisi deux fois pour le confirmer, puis cliquez sur Suivant.
  3. Choisissez le mot de passe secondaire (il protège les secrets), saisi deux fois lui aussi, puis cliquez sur Créer le profil ; Retour revient à la première étape en gardant ce que vous avez saisi. Le profil est créé, enregistré et ouvert aussitôt.

Le bouton Afficher / Masquer à côté de chaque champ de mot de passe révèle ce que vous avez tapé.

Le déverrouillage prend volontairement quelques secondes : cela rend la recherche d'un mot de passe beaucoup plus lente pour un attaquant. Pendant ce temps, la fenêtre est assombrie avec un message d'attente.

Fenêtre principale

La fenêtre comporte une barre d'outils en haut et trois colonnes :

  • à gauche : les coffres du profil ;
  • au centre : les éléments du coffre sélectionné ;
  • à droite : l'élément ouvert, affiché seulement quand un élément est ouvert.

Tant qu'aucun profil n'est ouvert, et quand il est verrouillé, l'écran d'accueil remplace les trois colonnes.

Coffres (colonne de gauche)

  • Cliquez sur un coffre pour afficher ses éléments. Les coffres sont toujours classés par ordre alphabétique.
  • + Nouveau coffre crée un coffre vide. Plusieurs coffres peuvent porter le même nom.
  • Un clic droit sur un coffre propose :
    • Renommer ;
    • Changer l'icône : choisissez une icône dans la grille (ou Aucune), puis sa couleur avec Choisir une couleur. La grille montre toujours les formes en noir ou en blanc (selon le thème) ; l'Aperçu montre la forme choisie dans la couleur choisie ;
    • Supprimer : supprime le coffre et tous ses éléments, après une confirmation qui indique combien il en contient.
  • Déposez des éléments sur un coffre pour les y déplacer (voir Éléments).

Éléments (colonne du centre)

  • La ligne du haut indique le nom du coffre et le nombre d'éléments affichés sur le total.
  • Rechercher un élément… filtre les éléments par nom (sans tenir compte des majuscules ni des accents).
  • Le choix du tri classe la liste par Nom (« item2 » avant « item10 »), Date de création ou Dernière modification ; le bouton flèche à côté inverse l'ordre. Le tri ne change que l'affichage.
  • Double-cliquez sur un élément, ou sélectionnez-le et appuyez sur Entrée, pour l'ouvrir à droite.
  • + Nouvel élément crée un élément vide et l'ouvre directement en mode modification.
  • Un clic droit sur un élément propose Ouvrir, Renommer, Changer l'icône, Dupliquer (une copie dans le même coffre) ou Supprimer (après confirmation, irréversible). Tant que l'élément est en cours d'édition à droite, Renommer, Changer l'icône et Dupliquer sont grisés : enregistrez ou annulez d'abord l'édition.
  • Pour déplacer des éléments vers un autre coffre, sélectionnez-les (Ctrl+clic, Maj+clic, ou Ctrl+A pour tous), puis faites-les glisser sur le coffre de destination et confirmez.

Affichage d'un élément (colonne de droite)

L'en-tête affiche le nom de l'élément, sa date de création, la date de sa dernière modification et son icône. Fermer masque l'affichage.

Mode lecture

  • Seuls les champs qui ont une valeur sont affichés.
  • Cliquez sur une valeur pour la copier dans le presse-papiers ; elle devient brièvement verte.
  • Les secrets (mots de passe, champs personnalisés chiffrés) sont masqués et restent chiffrés tant que vous ne les demandez pas : Afficher / Masquer les révèle, et un clic sur l'un d'eux le copie. Le mot de passe secondaire est demandé la première fois.
  • Un secret copié est effacé du presse-papiers après 30 secondes, au verrouillage du profil et à la fermeture de la fenêtre, sauf si vous avez copié autre chose entre-temps.
  • Codes TOTP affiche le code à 6 chiffres en cours et les secondes restantes avant qu'il change, tant que le profil est déchiffré (🔒 sinon : cliquez pour saisir le mot de passe secondaire). Un clic copie le code, jamais le secret.
  • Double-cliquez sur un site web, une adresse email ou un numéro de téléphone pour l'ouvrir dans votre navigateur, votre messagerie ou votre application d'appel, après confirmation.
  • Un ⚠ signale un site web, un email ou un numéro qui ne semble pas valide (survolez-le pour le détail).

Mode modification

Cliquez sur Modifier pour passer en mode modification (le mot de passe secondaire est demandé si besoin). Tous les champs sont alors affichés, en clair, et modifiables :

  • Tapez le nom de l'élément directement dans le titre.
  • + Ajouter une valeur ajoute une valeur à un champ ; ✕ à côté d'une valeur la supprime.
  • Générer, sous Mots de passe, ouvre le générateur de mots de passe ; le mot de passe obtenu est ajouté comme nouvelle valeur.
  • Les Codes TOTP se modifient sous forme de secret Base32 (la clé donnée par le site quand vous activez la double authentification).
  • + Champ personnalisé ajoute un champ au nom de votre choix, En clair (comme un identifiant) ou Chiffré (comme un mot de passe). Un champ personnalisé peut contenir plusieurs valeurs, chacune sur plusieurs lignes. Dans son en-tête : son nom (modifiez-le pour renommer le champ), ▲ / ▼ pour le déplacer, ✕ pour le supprimer. Plusieurs champs personnalisés peuvent porter le même nom.
  • Double-cliquez sur l'icône pour la changer : tapez dans la barre de recherche pour filtrer les logos fournis (la première correspondance est sélectionnée, Entrée valide), choisissez-en un dans la liste, utilisez Parcourir… pour prendre n'importe quelle image de votre ordinateur, ou Retirer pour l'icône par défaut. Couleur de fond remplit les parties transparentes de l'icône, pour qu'un logo ressorte sur votre thème ; Aucun les laisse transparentes. L'Aperçu à côté montre l'icône finale, logo et fond, telle que les listes l'affichent. L'image elle-même est enregistrée dans le profil : copier le profil sur un autre ordinateur garde ses icônes.

Enregistrer applique toutes les modifications à l'élément et revient en mode lecture : nom, valeurs, icône, et champs personnalisés ajoutés, renommés, déplacés ou supprimés. Annuler les abandonne toutes.

Si vous passez à un autre élément ou à un autre coffre, ou fermez l'affichage, avec des modifications non enregistrées, bippass demande s'il faut Enregistrer, Abandonner ou Annuler.

Les modifications appliquées à un élément sont gardées en mémoire : elles arrivent sur le disque quand le profil est enregistré (voir Enregistrement).

Générateur de mots de passe

Choisissez le type de mot de passe, réglez ses options, puis cliquez sur Générer (autant de fois que vous voulez).

Aléatoire

  • Longueur : de 1 à 256 caractères.
  • Minuscules (a-z), Majuscules (A-Z), Chiffres (0-9) : les types de caractères à utiliser.
  • Caractères spéciaux : cochez-le pour ajouter des caractères spéciaux ; la liste est modifiable, et ↺ rétablit celle par défaut.

Facile à retenir

  • Langue des mots : mots anglais, français ou espagnols.
  • Nombre de mots, Chiffres par mot et Séparateur entre les mots.
  • Mettre une majuscule à chaque mot.

Copier copie le résultat (effacé du presse-papiers après 30 secondes) ; Utiliser ce mot de passe l'ajoute à l'élément ; Annuler ferme sans l'utiliser.

Enregistrement et verrouillage

  • Les modifications restent en mémoire jusqu'à l'enregistrement du profil : avec Enregistrer dans la barre d'outils, Ctrl+S, ou Ctrl+K (enregistrer et quitter).
  • Chiffrer oublie le mot de passe secondaire : les secrets sont de nouveau masqués, jusqu'à ce que vous le saisissiez à nouveau.
  • Verrouiller (ou Ctrl+L) demande quoi faire des modifications de l'élément ouvert, enregistre le profil, le ferme (les deux mots de passe sont effacés de la mémoire) et revient à l'écran d'accueil : rouvrez-le avec son mot de passe primaire, ouvrez un autre profil ou créez-en un. Si l'enregistrement échoue, le profil reste ouvert.
  • Après une période d'inactivité (réglée dans Préférences), bippass verrouille le profil de la même façon, en appliquant sans demander les modifications de l'élément ouvert. Une boîte de dialogue restée ouverte est d'abord fermée.
  • À la fermeture de la fenêtre, bippass demande quoi faire des modifications de l'élément ouvert, puis s'il faut enregistrer les modifications non enregistrées.
  • Une fois la fenêtre fermée, les mots de passe sont effacés de la mémoire.
