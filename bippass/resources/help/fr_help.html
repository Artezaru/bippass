Principes

  • Un profil est un fichier chiffré sur votre ordinateur. Il contient tout le reste.
  • Un coffre regroupe des éléments, comme un dossier (par ex. « Travail », « Banque »). Il peut avoir sa propre icône et sa couleur.
  • Un élément correspond à un compte : ses identifiants, mots de passe, sites web, emails, numéros de téléphone, codes TOTP et champs personnalisés. Chaque champ peut contenir plusieurs valeurs.

Un profil est protégé par deux mots de passe :

  • le mot de passe primaire déchiffre le fichier du profil ;
  • le mot de passe secondaire déchiffre les secrets qu'il contient (mots de passe, secrets TOTP, champs personnalisés secrets).

Aucune récupération n'est possible : si vous perdez l'un des deux, le profil ne peut plus être ouvert.

Écran de démarrage

Le choix de la langue, en haut à droite, change la langue de toute l'application.

Ouvrir un profil

  1. Choisissez Ouvrir un coffre existant.
  2. Cliquez sur votre profil sous Profils existants, ou utilisez Parcourir… sous Ou choisissez un fichier pour un fichier rangé ailleurs. Le dernier fichier ouvert est prérempli.
  3. Saisissez le mot de passe primaire (Identifiants primaires), puis le mot de passe secondaire (Identifiants secondaires).

Créer un profil

  1. Choisissez Créer un nouveau profil et saisissez un nom d'utilisateur. L'écran indique où le profil sera enregistré (~/bippass/<nom>.encrypted). Un nom déjà utilisé est refusé.
  2. Choisissez le mot de passe primaire et saisissez-le une seconde fois pour le confirmer, puis faites de même pour le mot de passe secondaire.

Le bouton Afficher / Masquer à côté de chaque champ de mot de passe révèle ce que vous avez tapé.

Fenêtre principale

La fenêtre comporte une barre d'outils en haut et trois colonnes :

  • à gauche : les coffres du profil ;
  • au centre : les éléments du coffre sélectionné ;
  • à droite : l'élément ouvert, affiché seulement quand un élément est ouvert.

Coffres (colonne de gauche)

  • Cliquez sur un coffre pour afficher ses éléments. Les coffres sont triés par ordre alphabétique.
  • + Nouveau coffre crée un coffre vide.
  • Un clic droit sur un coffre propose :
    • Renommer ;
    • Icône… : choisissez une icône dans la grille (ou Aucune), puis sa couleur avec Choisir une couleur… ;
    • Supprimer : supprime le coffre et tous ses éléments, après une confirmation qui indique combien il en contient.
  • Déposez des éléments sur un coffre pour les y déplacer (voir Éléments).

Éléments (colonne du centre)

  • La ligne du haut indique le nom du coffre et le nombre d'éléments affichés sur le total.
  • Rechercher un élément… filtre les éléments par nom.
  • Le choix du tri les classe par ordre Alphabétique, Alphanumérique (« item2 » avant « item10 ») ou par Date de dernière modification ; le bouton flèche à côté inverse l'ordre.
  • Double-cliquez sur un élément, ou sélectionnez-le et appuyez sur Entrée, pour l'ouvrir à droite.
  • + Nouvel élément crée un élément vide et l'ouvre directement en mode modification.
  • Un clic droit sur un élément propose Ouvrir, Renommer, Icône…, Dupliquer (une copie dans le même coffre) ou Supprimer (après confirmation, irréversible).
  • Pour déplacer des éléments vers un autre coffre, sélectionnez-les (Ctrl+clic, Maj+clic, ou Ctrl+A pour tous), puis faites-les glisser sur le coffre de destination et confirmez.

Affichage d'un élément (colonne de droite)

L'en-tête affiche le nom de l'élément, la date de sa dernière modification et son icône. Fermer masque l'affichage.

Mode lecture

  • Seuls les champs qui ont une valeur sont affichés.
  • Cliquez sur une valeur pour la copier dans le presse-papiers ; elle devient brièvement verte.
  • Les mots de passe sont masqués : Afficher / Masquer les révèle. La copie copie toujours la vraie valeur.
  • Codes TOTP affiche le code à 6 chiffres en cours et les secondes restantes avant qu'il change. Un clic copie le code, jamais le secret.
  • Double-cliquez sur un site web, une adresse email ou un numéro de téléphone pour l'ouvrir dans votre navigateur, votre messagerie ou votre application d'appel, après confirmation.
  • Un ⚠ signale un site web, un email ou un numéro qui ne semble pas valide (survolez-le pour le détail).

Mode modification

Cliquez sur Modifier pour passer en mode modification. Tous les champs sont alors affichés, en clair, et modifiables :

  • Tapez le nom de l'élément directement dans le titre.
  • + Ajouter une valeur ajoute une valeur à un champ ; ✕ à côté d'une valeur la supprime.
  • Générer, sous Mots de passe, ouvre le générateur de mots de passe ; le mot de passe obtenu est ajouté comme nouvelle valeur.
  • Les Codes TOTP se modifient sous forme de secret Base32 (la clé donnée par le site quand vous activez la double authentification).
  • + Champ personnalisé ajoute un champ au nom de votre choix : SCALAR pour du texte en clair, ENCRYPTED pour un secret. ✕ dans l'en-tête d'un champ personnalisé le supprime.
  • Double-cliquez sur l'icône pour la changer : tapez dans la barre de recherche pour filtrer les logos fournis (la première correspondance est sélectionnée, Entrée valide), choisissez-en un dans la liste, ou utilisez Parcourir… pour prendre n'importe quelle image de votre ordinateur.

Enregistrer applique les modifications à l'élément et revient en mode lecture ; Annuler les abandonne. L'icône et les champs personnalisés ajoutés ou supprimés sont appliqués tout de suite : Annuler ne les défait pas.

Si vous passez à un autre élément ou à un autre coffre, ou fermez l'affichage, avec des modifications non enregistrées, bippass demande s'il faut Enregistrer, Abandonner ou Annuler.

Les modifications appliquées à un élément sont gardées en mémoire : elles arrivent sur le disque quand le profil est enregistré (voir Enregistrement).

Générateur de mots de passe

Choisissez le type de mot de passe, réglez ses options, puis cliquez sur Générer (autant de fois que vous voulez).

Aléatoire

  • Longueur : de 1 à 256 caractères.
  • Minuscules (a-z), Majuscules (A-Z), Chiffres (0-9) : les types de caractères à utiliser.
  • Caractères spéciaux : cochez-le pour ajouter des caractères spéciaux ; la liste est modifiable, et ↺ rétablit celle par défaut.

Facile à retenir

  • Langue des mots : mots anglais, français ou espagnols.
  • Nombre de mots, Chiffres par mot et Séparateur entre les mots.
  • Mettre une majuscule à chaque mot.

Copier copie le résultat ; Utiliser ce mot de passe l'ajoute à l'élément ; Annuler ferme sans l'utiliser.

Enregistrement et verrouillage automatique

  • Les modifications restent en mémoire jusqu'à l'enregistrement du profil : avec Enregistrer dans la barre d'outils, Ctrl+S, ou Ctrl+K (enregistrer et quitter).
  • À la fermeture de la fenêtre, bippass demande quoi faire des modifications de l'élément ouvert, puis s'il faut enregistrer les modifications non enregistrées.
  • Après une période d'inactivité (réglée dans Préférences), bippass applique les modifications de l'élément ouvert, enregistre le profil et se ferme. Si l'enregistrement échoue, la fenêtre reste ouverte.
  • Une fois la fenêtre fermée, les mots de passe sont effacés de la mémoire.
